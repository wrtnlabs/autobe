## 1. Wrtn 내부 관리자 접근 가능 데이터 {#wrtn-내부-관리자}

### 1.1 기업 관리 데이터

- **전체 기업 목록 및 기본 정보**
    - 기업명, 사업자등록번호, 대표자명
    - 가입 일자, 승인 일자, 상태
    - 계약 플랜, 요금제
    - 마스터 계정 정보 (이름, 이메일)
- **기업 승인/거부 이력**
    - 가입 신청 정보
    - 승인/거부 사유
    - 처리한 관리자 정보
- **기업 설정 정보**
    - 결제 정보 (사업자등록번호, 세금계산서 이메일)
    - 할당량 설정
    - 활성화된 기능/모듈
    - 제공 LLM 설정

### 1.2 사용량 및 통계 데이터

- **전사 사용량 집계**
    - 기업별 총 토큰 사용량
    - 기업별 총 비용
    - 기간별 사용 추이
    - 모델별 사용 분포
- **서비스 품질 메트릭**
    - API 응답 시간
    - 에러율
    - 동시 접속자 수
    - 시스템 부하
- **집계된 통계만 (개별 내용 불가)**
    - 기업당 평균 세션 수
    - 기업당 평균 직원 수
    - 도구별 사용 빈도
    - 개별 채팅 내용은 접근 불가

### 1.3 과금 및 결제 데이터 (Optional)

- **청구 및 결제 정보 (Optional)**
    - 청구서 발행 내역
    - 결제 완료/미결제 상태
    - 연체 정보
    - 환불 이력
- **매출 분석 데이터 (Optional)**
    - 기업별 MRR (월간 반복 매출)
    - 결제 성공률
    - 이탈률 (Churn Rate)

### 1.4 시스템 로그 및 감사

- **시스템 레벨 로그**
    - 서버 에러 로그
    - 성능 모니터링 로그
    - 보안 이벤트 로그
- **관리자 작업 이력**
    - 기업 승인/거부 이력
    - 시스템 설정 변경 이력
    - 긴급 조치 이력
- **제한적 감사 로그**
    - 비정상적 사용 패턴 감지 시에만
    - 보안 사고 조사 시에만
    - 법적 요청이 있을 경우에만

### 1.5 고객 지원 데이터 (CS 처리 방법에 따라 상이 / 채널톡 쓰면 무관)

- **고객센터 문의 내역**
    - 모든 기업의 문의 티켓
    - 문의 내용 및 답변
    - 처리 상태
- **공지사항 및 알림**
    - 발송한 공지사항 목록
    - 알림 전송 이력
    - 읽음/미읽음 통계

### 1.6 접근 불가 데이터

- **개별 채팅 내용** - 완전 차단
- **개인 서포터 설정** - 완전 차단
- **직원 개인 설정** - 완전 차단
- **세부 업무 내용** - 완전 차단
- **비밀번호 (해시 포함)** - 열람 불가
- **개인 파일 내용** - 열람 불가

### 접근 원칙

```
내부 관리자는 시스템 운영 및 고객 지원을 위한
메타데이터와 집계 데이터만 접근 가능.
실제 업무 콘텐츠와 개인정보는 엄격히 차단.
```

## 2. 고객사 마스터 접근 가능 데이터 {#고객사-마스터}

### 2.1 자사 기업 정보

- **기업 기본 정보**
    - 기업명, 사업자등록번호
    - 대표자명, 주소
    - 세금계산서 이메일
    - 계약 플랜 및 상태 (추후 구현)
- **기업 설정 정보**
    - 활성화된 도구(프로시저) 목록
    - 전사 권한 설정
    - 할당량 정보

### 2.2 조직 구조 데이터

- **전체 조직도**
    - 모든 팀/부서 목록
    - 팀 계층 구조
    - 팀별 인원 수
- **전체 직원 정보**
    - 전체 직원 명단
    - 직원별 소속 팀
    - 직원별 역할 (마스터/관리자/일반)
    - 직원 초대 이력

### 2.3 사용량 및 통계 (전사)

- **전사 사용량 통계**
    - 전체 토큰 사용량
    - 전체 비용
    - 기간별 사용 추이
    - 할당량 대비 사용률
- **팀별 통계**
    - 팀별 사용량
    - 팀별 비용
    - 팀별 활성 사용자 수
- **직원별 통계**
    - 직원별 사용량
    - 직원별 비용
    - 직원별 세션 수
- **도구/모델별 통계**
    - 도구별 사용 빈도
    - 모델별 사용 분포
    - 도구별 실행 횟수

### 2.4 세션 및 이력 데이터 (MVP에서는 뤼튼에 직접 요청)

- **전체 세션 목록**
    - 모든 직원의 채팅 세션 제목
    - 세션 생성 일시
    - 세션 소유자 정보
    - 세션 상태 (활성/아카이브/삭제)
- **채팅 내용 제한적 접근**
    - 세션 제목/요약만 기본 제공
    - 상세 내용은 직접 열어봐야 함
    - 삭제된 세션은 접근 불가
- **도구 실행 이력**
    - 전체 도구 실행 로그
    - 실행자, 실행 시간
    - 실행 결과 (성공/실패)

### 2.5 파일 관리 (MVP에서는 뤼튼에 직접 요청)

- **전체 파일 목록**
    - 모든 업로드된 파일 메타데이터
    - 파일명, 크기, 업로더
    - 업로드 일시
- **파일 다운로드**
    - 마스터는 모든 파일 다운로드 가능
    - 단, 감사 로그에 기록됨

### 2.6 과금 및 결제 (MVP에서는 구현 X)

- **청구 정보**
    - 모든 청구서 조회
    - 청구 내역 상세
    - 결제 이력
- **결제 관리**
    - 결제 정보 수정
    - 결제 수단 변경
    - 영수증/세금계산서 다운로드

### 2.7 권한 및 역할 관리

- **권한 설정 이력 (MVP에서는 구현 X)**
    - 모든 권한 변경 로그
    - 역할 변경 이력
    - 변경자 정보
- **도구 권한 관리**
    - 전사 도구 권한 설정/변경
    - 팀별 도구 권한 설정/변경

### 2.8 감사 로그 (뤼튼에 직접 요청)

- **전사 감사 로그**
    - 모든 직원의 로그인 이력
    - 중요 작업 로그 (권한 변경, 데이터 삭제)
    - 보안 이벤트

### 2.9 접근 불가 데이터

- **다른 기업 데이터** - 완전 차단
- **직원 비밀번호** - 열람 불가
- **직원 개인 서포터 설정 내용** - 열람 불가 (설정 여부만 확인 가능)
- **Wrtn 내부 관리 정보** - 차단

### 💡 접근 원칙

```
마스터는 자사 전체 데이터에 대한 포괄적 접근 권한 보유.
단, 개인 민감 정보(비밀번호, 개인 설정)는 제외.
모든 접근은 감사 로그에 기록됨.
```

## 3. 고객사 일반 관리자 접근 가능 데이터 {#고객사-일반-관리자}

### 3.1 소속 팀 정보

- **관리하는 팀 정보**
    - 자기 팀 및 하위 팀 구조
    - 팀별 인원 수
    - 팀 설정 정보
- **다른 팀 정보** - 접근 불가

### 3.2 소속 구성원 정보

- **관리 범위 직원 정보**
    - 자기 팀 및 하위 팀 직원 명단
    - 직원 이름, 이메일, 역할
- **직원 초대/관리**
    - 소속 팀에 직원 초대
    - 소속 직원 역할 변경 (일반 직원 ↔ 일반 관리자)
- **다른 팀 직원** - 접근 불가
- **마스터 정보** - 조회만 가능, 수정 불가

### 3.3 사용량 및 통계 (소속 범위)

- **자기 팀 통계**
    - 자기 팀 및 하위 팀 사용량
    - 팀별 비용
    - 기간별 추이
- **소속 직원 통계**
    - 관리 범위 직원별 사용량
    - 직원별 비용
    - 직원별 활성도
- **전사 통계** - 접근 불가
- **다른 팀 통계** - 접근 불가

### 3.4 세션 및 이력 데이터 (MVP에서는 뤼튼에 직접 요청)

- **소속 직원 세션 목록**
    - 관리 범위 직원의 세션 제목
    - 세션 생성 일시
    - 세션 소유자
- **채팅 내용**
    - 세션 제목만 기본 제공
    - 상세 내용은 접근 제한 (권한 정책에 따라 다를 수 있음)
- **도구 실행 이력**
    - 소속 직원의 도구 실행 로그

### 3.5 권한 관리

- **소속 팀 권한 설정**
    - 자기 팀 및 하위 팀의 도구 권한 설정
    - 단, 전사 권한이 비활성화면 활성화 불가
- **전사 권한 설정** - 불가
- **다른 팀 권한** - 불가

### 3.6 파일 관리 (MVP에서는 뤼튼에 직접 요청)

- **소속 직원 파일 목록**
    - 관리 범위 직원이 업로드한 파일 메타데이터
- **파일 다운로드**
    - 정책에 따라 제한 가능
    - 다운로드 시 감사 로그 기록

### 3.7 대시보드

- **소속 팀 대시보드**
    - 자기 팀 및 하위 팀 대시보드 접근
    - 실시간 사용량 모니터링
- **전사 대시보드** - 접근 불가
- **다른 팀 대시보드** - 접근 불가

### 3.8 감사 로그 (뤼튼에 직접 요청)

- **소속 범위 감사 로그**
    - 관리 범위 직원의 로그인 이력
    - 소속 팀 내 권한 변경 로그
- **전사 감사 로그** - 접근 불가

### 3.9 접근 불가 데이터

- **전사 통계 및 과금 정보**
- **다른 팀 데이터**
- **기업 설정 변경**
- **결제 정보**
- **마스터 권한 작업**

### 💡 접근 원칙

```
일반 관리자는 자기가 관리하는 팀과
그 하위 팀의 데이터만 접근 가능.
상위 팀이나 다른 부서는 완전 차단.
```

## 4. 고객사 일반 직원 접근 가능 데이터 {#고객사-일반-직원}

### 4.1 개인 정보

- **본인 프로필**
    - 이름, 이메일
    - 소속 팀
    - 권한
- **개인 설정**
    - 서포터 설정 (스킨, 이름, 말투)
    - 테마 설정
    - 알림 설정

### 4.2 본인 세션 및 이력

- **본인 채팅 세션**
    - 본인이 생성한 채팅 세션 전체
    - 채팅 내용 전체
    - 채팅 이력
- **본인 도구 실행 이력**
    - 본인이 실행한 도구 로그
    - 실행 결과
- **다른 직원 세션** - 완전 차단
- **공유되지 않은 세션** - 접근 불가

### 4.3 본인 파일

- **본인 업로드 파일**
    - 본인이 업로드한 파일 목록
    - 파일 다운로드
    - 파일 삭제
- **다른 직원 파일** - 접근 불가

### 4.4 조직 정보 (제한적)

- **기본 조직 정보**
    - 기업명
    - 본인 소속 팀
- **다른 팀 정보** - 접근 불가
- **전체 조직도** - 접근 불가

### 4.5 사용 가능한 도구/프로시저

- **허용된 도구 목록**
    - 본인에게 허용된 도구/프로시저
    - 도구 설명 및 사용법
- **비활성화된 도구** - 목록에서 숨김

### 4.6 공지사항 및 지원

- **공지사항**
    - 전사 또는 본인 대상 공지
    - 읽음/미읽음 관리
- **고객센터**
    - 본인 문의 등록
    - 본인 문의 이력 조회

### 4.8 접근 불가 데이터

- **관리 메뉴 전체** - 완전 차단
- **대시보드** - 접근 불가
- **다른 직원 데이터** - 완전 차단
- **조직 관리 기능** - 차단
- **권한 설정** - 차단
- **과금 정보** - 차단
- **감사 로그** - 차단

### 💡 접근 원칙

```
일반 직원은 본인의 데이터와
AI 사용에 필요한 최소한의 정보만 접근 가능.
조직 관리 및 타인 데이터는 완전 차단.
```

## 5. 접근 불가 데이터 (모든 역할) {#접근-불가-데이터}

### 5.1 절대 접근 불가 (시스템 레벨)

```
비밀번호 원문 - 누구도 열람 불가
비밀번호 해시 - 내부 관리자도 불가
암호화 키 - 시스템만 보유
```

### 5.2 격리된 데이터

```
타 기업 데이터 - 완전 격리
삭제된 데이터 - 복구 기간 외 접근 불가
```
