    Interface AutoBeInterfaceSchemaDecoupleEvent

    Event fired when the Interface agent resolves one cross-type circular reference cycle in OpenAPI schema definitions.

    Each detected cycle is processed independently: one LLM call per cycle, one event dispatched per cycle. Multiple events may be emitted when multiple cycles are detected in the schema graph.

    Cross-type circular references (A → B → A, or A → B → C → A) make code generation impossible because they create infinite type recursion. The Decouple agent programmatically detects these cycles using Tarjan's SCC algorithm, then uses LLM judgment to decide which property reference(s) to remove to break each cycle while preserving semantic integrity.

    Self-references (A → A) are NOT treated as circular references — they represent legitimate tree structures (categories, org charts) and are handled by the existing VariadicSingleton pattern in the Realize phase.
