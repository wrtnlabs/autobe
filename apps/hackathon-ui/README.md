Hackathon frontend for [AutoBE](https://github.com/wrtnlabs/autobe).

React + Material-UI chat application connecting to the hackathon server via WebSocket.

## Scripts

```bash
pnpm run dev            # Dev server (QA mode)
pnpm run build          # Build (QA mode)
pnpm run build:prod     # Build (production mode)
```
