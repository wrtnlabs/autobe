Benchmark dashboard and pipeline monitor for [AutoBE](https://github.com/wrtnlabs/autobe).

React + MUI + Recharts application that visualizes benchmark results and pipeline execution status. Built output is embedded into `@autobe/website` at the `/dashboard` route.

## Scripts

```bash
pnpm run dev            # Dev server
pnpm run build          # Build for production
```
