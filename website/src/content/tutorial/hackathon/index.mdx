## 1. Overview

https://hackathon.autobe.dev

위 URL 주소로 접속하시어, AutoBE 로 백엔드 어플리케이션을 만들고 리뷰해주세요.

AI 모델은 (`openai/gpt-4.1-mini` -> `openai/gpt-4.1`) 순서로 사용해주시면 되며, 만들고자 하는 백엔드 어플리케이션의 주제는 자유로이 정하시면 됩니다.

## 3. AI Model Specification

![](/images/hackathon/config.png)

> AI 모델 사용 순서: `openai/gpt-4.1-mini` -> `openai/gpt-4.1`

새 채팅을 시작하며, 채팅에 사용할 AI 모델을 선택해주세요. 첫 채팅에서는 `openai/gpt-4.1-mini` 를 선택하여 진행해주세요. 

`openai/gpt-4.1` 은 `openai/gpt-4.1-mini` 로 백엔드 어플리케이션을 생성한 뒤, 리뷰 게시물을 작성한 뒤에라야 이용할 수 있습니다. 따라서 `openai/gpt-4.1-mini` 를 충분히 사용해보신 후, `openai/gpt-4.1` 로 백엔드 어플리케이션을 생성해보시기 바랍니다.

그리고 `qwen/qwen3-235b-a22b-2507` 는 재미를 위해 넣어두었습니다. 실제로 `qwen/qwen3-235b-a22b-2507` 는 백엔드 어플리케이션의 생성 성공률이 매우 낮으니, 본 해커톤 대회의 일정을 모두 소화하신 후, 여유가 되실 때 흥미 본위로 사용해주시기 바랍니다.

- `openai/gpt-4.1-mini` (essential)
- `openai/gpt-4.1` (essential, but after review mini)
- `qwen/qwen3-235b-a22b-2507` (optional, low success rate)

### 3.1. `openai/gpt-4.1-mini`

![](/images/demonstrate/replay-openai-gpt4.1-mini.png)

여러분이 가장 먼저 사용하시게 될 모델입니다.

작고 값싼 모델로써, 가성비 있게 백엔드 어플리케이션을 만들 수 있습니다.

그러나 모델 사이즈의 한계로 인해, 심층적인 요구사항 분석을 잘 못합니다. 그리고 요구사항 분석 정의서나 ERD 해설본 등, 각종 문서들의 완성도가 떨어질 수도 있습니다. 더불어 가끔씩 컴파일 에러를 해소하지 못하여, AutoBE 가 생성한 백엔드 어플리케이션이 빌드 실패할 수도 있습니다.

여러분은 본 해커톤 대회에서 `openai/gpt-4.1-mini` 모델을 최대 3 번 사용할 수 있으니, 다양한 주제로 AutoBE 를 다각도로 체험해보시기 바랍니다.

### 3.2. `openai/gpt-4.1`

![](/images/demonstrate/replay-openai-gpt4.1.png)

> 여러분은 이 모델을, 위 `openai/gpt-4.1-mini` 로 백엔드 어플리케이션을 생성하고 리뷰 게시물을 작성하신 뒤, 사용하실 수 있습니다.

크기 비싼 모델로써, 여러분은 이 `openai/gpt-4.1` 을 통해 가장 완벽한 백엔드 어플리케이션을 만들 수 있습니다.

심층적인 요구사항 분석에도 탁월하며, "나 삼성전자 회장인데 우리 회사의 조직 특성을 고려해서 ERP 시스템 만들어줘, 아무런 질문도 하지말고 니가 가진 모든 지식을 동원해서 알아서 해" 류의 막무가내식 요구사항도 잘 소화해냅니다. 요구사항 분석 정의서나 ERD 해설본 등의 퀄리티도 뛰어나고, 컴파일 에러 또한 매우 잘 이해하고 곧잘 해소해냅니다.

그러나 그만큼 가격이 비쌉니다. Amazon 급 쇼핑몰 기준, 약 400 달러의 비용이 소요됩니다. 때문에 저희도 이 모델을 해커톤 대회에서 무제한 제공해드리지 못하고, `openai/gpt-4.1-mini` 미션을 완수한 뒤에 딱 한 번만 사용할 수 있도록 제한을 두고 있습니다.



### 3.3. `qwen/qwen3-235b-a22b-2507`

![](/images/demonstrate/replay-qwen3-235b-a22b.png)

가장 싸고 가벼운 모델로써, 개발자들이 사용하는 노트북에서도 무리없이 구동 가능한 모델입니다.

그러나 to do list 급 간단한 백엔드 어플리케이션만 제작이 가능하며, 조금만 요구사항이 복잡하거나 방대해져도 곧잘 고장나버리고는 합니다.

재미를 위해 넣어둔 모델로써, 본 모델에 대한 리뷰는 필수가 아닙니다. 여러분이 여유가 되실 때, 흥미 본위로 사용해주시기 바랍니다.

## 4. Conversation

![](/images/hackathon/conversate.png)

AutoBE 챗봇과 대화하여, 백엔드 어플리케이션을 만들어주세요.

아래는 시사/경제 토론 게시판을 만들 때 사용한 예시입니다. 그러나 아래 대화와 같이, 아무튼 알아서 해줘식의 대화는 지양해주세요. 여러분이 원하는 요구사항들에 대하여, AI 와 충분히 토론해주세요.

> I want to create a political/economic discussion board.
>
> Since I'm not familiar with programming, please write a requirements analysis report as you see fit.

AutoBE 챗봇과 요구사항에 대하여 충분히 토의하였다면, AutoBE 는 곧 요구사항 분석 보고서를 발행해 줄 것입니다. 요구사항 정의서 발행에는 약 5 ~ 15 분 정도의 시간이 소요되니, 그동안 다른 일을 하시거나, 잠시간 휴식을 취하신 뒤에 돌아오셔도 됩니다.

이후로는 각 단계에 따라 다음과 같은 대화들을 입력하시면, AutoBE 가 차례대로 작업을 진행하며 백엔드 어플리케이션을 만들어 줄 것입니다. 그리고 이 때부터는 각 단계별로 소요되는 시간이 지난하게 길어지니, 그동안 다른 일을 하셔도 좋습니다.

- Design the database schema.
- Create the API interface specification.
- Make e2e test functions.
- Implement the API functions.

각 단계마다 소요되는 개략적인 시간은, 이전 [3. AI Model Specification](#3-ai-model-specification) 의 각 모델별 예제 스크린샷들을 참고해주세요.

### 4.1. Analyze
AutoBE 가 당신과의 대화 내용을 바탕으로, 요구사항을 정의하고 이에 대한 분석 보고서를 발행해줍니다.

- 요구사항 분석 보고서 예시:
  - [To Do List](https://github.com/wrtnlabs/autobe-example-todo/tree/main/docs/analysis)
  - [Reddit like Community](https://github.com/wrtnlabs/autobe-example-reddit/tree/main/docs/analysis)
  - [Political/Economic Discussion Board](https://github.com/wrtnlabs/autobe-example-bbs/tree/main/docs/analysis)
  - [E-Commerce](https://github.com/wrtnlabs/autobe-example-shopping/tree/main/docs/analysis)

당신이 원하는 백엔드 어플리케이션의 요구사항에 대하여, AutoBE 가 끊임없이 질문을 던지며 토론을 이어나갈 것입니다. AutoBE 가 요구사항이 충분히 도출되었다고 판단하면, 어떠한 스토리로 요구사항 분석 보고서를 발행할지 물어볼 것이며, 이 때 동의한다고 말하시면 그대로 요구사항 분석 보고서가 발행됩니다.

만일 AutoBE 의 질문이 지나치게 세세하거나 아니면 만들고자 하는 주제에 대하여 세세하게 알지 못한다면, AutoBE 에게 더 이상의 질문으로 그만두고 재량적으로 판단하여 요구사항을 정의해달라고 하세요. 그러면 AutoBE 가 스스로 판단하여 요구사항을 정의하고 이에 대한 분석 보고서를 발행해줄 것입니다.

여러분은 이렇게 발행된 요구사항 분석 보고서를 읽어보시고, 리뷰 게시물을 써주시면 됩니다. AutoBE 가 실제로 여러분이 원하는 요구사항을 제대로 도출하였는지, 아니면 중대 사항을 누락하거나 또는 필요 이상으로 세세하게 요구사항을 정의하였는지 등을 살펴보시고, 이에 대하여 논평해주세요.
