Why is the distribution so uniform? Because AutoBe fixes the output shape. Every model fills the same AST structure, and the compiler rejects anything that doesn't fit. The model's "personality" gets erased — what survives is only what the compiler approves. So `qwen3.5-27b` and `claude-sonnet-4.6` produce nearly identical backends. Bigger models just need fewer retries.

**Different models, same result.** Self-host and the cost drops to electricity.

## How It Works

AutoBe doesn't ask LLMs to write free-form text code. Instead, LLMs fill compiler AST structures through function calling — database schemas, API specs, test definitions, implementation code.

Our four AI-native compilers (Database, OpenAPI, Test, TypeScript) validate the output, diagnose exactly what's wrong, and feed structured errors back to the LLM. The LLM corrects only the broken parts and resubmits. This loop repeats until every compiler says "pass."

> *"If you can verify, you converge."*

For the full story — compound effect math, the Pink Elephant Problem, why small models make the best QA engineers — see the deep dives at the bottom.

Here's what one of those AST structures looks like — this is the test expression type that LLMs fill through function calling:

```typescript
export namespace AutoBeTest {
  export type IExpression =
    | IBooleanLiteral   | INumericLiteral    | IStringLiteral     // literals
    | IArrayLiteralExpression  | IObjectLiteralExpression         // compound literals
    | INullLiteral      | IUndefinedKeyword                       // null/undefined
    | IIdentifier       | IPropertyAccessExpression               // accessors
    | IElementAccessExpression | ITypeOfExpression                // access/operations
    | IPrefixUnaryExpression   | IPostfixUnaryExpression          // unary operations
    | IBinaryExpression                                           // binary operations
    | IArrowFunction    | ICallExpression    | INewExpression     // functions
    | IArrayFilterExpression   | IArrayForEachExpression          // array operations
    | IArrayMapExpression      | IArrayRepeatExpression           // array operations
    | IPickRandom       | ISampleRandom      | IBooleanRandom     // random generation
    | IIntegerRandom    | INumberRandom      | IStringRandom      // random generation
    | IPatternRandom    | IFormatRandom      | IKeywordRandom     // random generation
    | IEqualPredicate   | INotEqualPredicate                      // assertions
    | IConditionalPredicate    | IErrorPredicate;                 // assertions
}
```
